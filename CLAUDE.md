# macuartin blog

## Reglas de escritura

- No usar emdashes (—). Usar comas, dos puntos o reestructurar la oración.
- No usar términos específicos de una sola industria (ej: "risk ops", "payment ops"). Usar ejemplos concretos de múltiples industrias (fintech, banca, retail, seguros) para que el contenido sea universal.
- El blog está en español. Los términos técnicos en inglés son aceptables cuando son de uso común (ownership, builder, workflow, etc).

## Stack

- Astro 5.7 con MDX, RSS, Sitemap
- Deploy en GitHub Pages (macuartin.com)
- Colecciones: posts, notes, projects
